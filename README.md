
# Bioinformatics Workshop
### Introduction to Transcriptomics Data Analysis

Welcome to the **AI & Bioinformatics Workshop**.

This workshop provides a practical introduction to modern transcriptomics technologies, public omics resources, and basic single-cell RNA-seq analysis using **R** and **Seurat**.

The workshop is designed for researchers with little or no prior experience in bioinformatics who would like to understand how transcriptomics data are generated, shared, and analyzed.

---

# Workshop Overview

The workshop consists of **three sections**.

## Part 1 — Transcriptomics Technologies

An overview of the major transcriptomics technologies, including:

- Bulk RNA-seq
- Single-cell RNA-seq
- Spatial transcriptomics

Topics include:

- What each technology measures
- Advantages and limitations
- When to use each technology
- Choosing the appropriate technology for different biological questions

---

## Part 2 — Public Transcriptomics Resources

Learn how transcriptomics datasets are shared and how to systematically locate publicly available datasets.

Topics include:

- Primary data repositories
- Curated and integrated data resources
- Disease-specific databases
- Common transcriptomic data formats
- Best practices for finding public datasets

---

## Part 3 — Hands-on Analysis in R

This section contains the practical exercises used during the workshop.

Participants will perform a complete single-cell RNA-seq analysis using **Seurat**.

The repository includes:

-You can download the following information from this link: https://drive.google.com/drive/folders/1v1iPHKiQEevgLhdOovR0b_1K4QYjqew0?usp=sharing 

- 📄 **RNAseq_Workshop.Rmd** — Complete analysis workflow
- 📂 **Example single-cell RNA-seq dataset** — Input data for the practical session
  
The practical session covers:

- Loading data
- Quality control
- Cell filtering
- Normalization
- Dimensionality reduction
- Batch correction
- Clustering
- Marker gene identification

By the end of this workshop, participants should be able to:

- Understand the major transcriptomics technologies.
- Navigate public omics resources.
- Locate and download public transcriptomics datasets.
- Recognize common transcriptomic data formats.
- Perform a basic single-cell RNA-seq analysis using **Seurat**.
